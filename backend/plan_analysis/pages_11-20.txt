**3.1. संग्रहालय और अभिलेखीय एपीआई (Museum & Archival APIs)**

**Hindi Description (हिंदी विवरण):**
एपीआई कलाकृतियों के मेटाडेटा और उच्च-रिज़ॉल्यूशन वाली छवियां प्रदान करते हैं, जो अक्सर क्रिएटिव कॉमन्स जीरो (CCO) लाइसेंस के तहत होती हैं।
मेट्रोपॉलिटन म्यूजियम ऑफ आर्ट एपीआई और क्लीवलैंड म्यूजियम ऑफ आर्ट एपीआई 470,000 से अधिक कलाकृतियों तक मुफ्त पहुंच प्रदान करते हैं। एक एजेंट फिल्म में दृश्य संपत्ति के रूप में उपयोग करने के लिए "सिंधु घाटी सभ्यता" की मुहरों, गहनों और बर्तनों की छवियों को पुनः प्राप्त कर सकता है। इंटरनेट आर्काइव्ड एपीआई लाइब्रेरी पुस्तकों, फिल्मों और ऑडियो फ़ाइलों का खजाना है। इंटरनेटआर्काइव पायथन लाइब्रेरी एजेंटों को सार्वजनिक डोमेन फुटेज (जैसे, "1940 के न्यूज़रील") खोजने और उन्हें नई सामग्री में रीमिक्स करने के लिए प्रोग्रामेटिक रूप से डाउनलोड करने की अनुमति देती है 20।
भारतीय संदर्भ के लिए, भारतीय पुरातत्व सर्वेक्षण (ASI) और राष्ट्रीय संग्रहालय, नई दिल्ली की डिजिटल रिपोजिटरी महत्वपूर्ण होती है। हालांकि उनके एपीआई काफी मानकपिक नहीं हो सकते हैं, data.gov.in के माध्यम से उपलब्ध हेरोडॉट भारतीय स्मारकों और विरासत स्थलों के बारे में विस्तृत जानकारी प्रदान करते हैं 22।

**English Description (अंग्रेजी विवरण):**
APIs provide metadata and high-resolution images of artifacts, often under Creative Commons Zero (CCO) licenses.
The Metropolitan Museum of Art API and Cleveland Museum of Art API offer free access to over 470,000 artifacts. An agent can retrieve images of "Indus Valley Civilization" seals, jewelry, and pottery for use as visual assets in films. The Internet Archived APIs are a treasure trove of books, films, and audio files. The InternetArchive Python library allows agents to programmatically download public domain footage (e.g., "1940s newsreels") for finding and remixing into new content 20.
For the Indian context, the digital repositories of the Archaeological Survey of India (ASI) and the National Museum, New Delhi, are important. Although their APIs may not be very standard, data.gov.in provides detailed information about Herodotean Indian monuments and heritage sites 22.

**3.2. ऐतिहासिक भूगोल और घटनाएँ (Historical Geography & Events)**

**Hindi Description (हिंदी विवरण):**
OpenHistoricalMap "मानचित्रों की टाइम मशीन" है। यह एक समय आयाम के साथ मानचित्र डेटा संग्रहीत करता है। एजेंट ऐतिहासिक प्रवृत्तियों के लिए महत्वपूर्ण, सदियों स�� बदलती सीमाओं को दिखाने वाले मानचित्रों को प्रस्तुत करने के लिए वेक्टर डेटा निकाल सकते हैं 23। प्रोजेक्ट गुटेनबर्ग एपीआई (Gutenberg.ex API) एजेंटों को उद्धरण प्राप्त करने, घटनाओं को सारांशित करने, या प्राथमिक स्रोतों के आधार पर स्क्रिप्ट लिखने के लिए क्लासिक साहित्य और ऐतिहासिक ग्रंथों को निकालने की अनुमति देता है 24। GDELT प्रोजेक्ट घटनाओं, भाषा और टोन का एक वैश्विक डेटाबेस है, जो ऐतिहासिक सामाजिक भावनाओं के विश्लेषण के लिए अद्वितीय है।

**English Description (अंग्रेजी विवरण):**
OpenHistoricalMap is a "time machine for maps." It stores map data with a time dimension. Agents can extract vector data to represent maps showing changing borders over centuries, which is crucial for historical trends 23. The Project Gutenberg API (Gutenberg.ex API) allows agents to retrieve quotes, summarize events, or extract classic literature and historical texts for scriptwriting based on primary sources 24. The GDELT Project is a global database of events, language, and tone, which is unique for analyzing historical social sentiments.

**Hindi Description (हिंदी विवरण):**
Postiz एक ओपन-सोर्स सोशल मीडिया शेड्यूलर है और HootSuite का एक शक्तिशाली स्व-होस्टेड विकल्प है। यह X (Twitter), LinkedIn, Facebook आदि का समर्थन करता है। एकीकृतः एक एजेंट एक वीडियो बनाता है, एक एलएलएम का उपयोग करके कैप्शन लिखता है, और Postiz एपीआई का उपयोग करके इसे सभी प्लेटफार्मों पर एक साथ शेड्यूल करता है 29। Instagrapi Instagram के लिए एक अनौपचारिक एपीआई रैपर है जो एजेंटों को फोन के बिना फोटो/वीडियो अपलोड करने और इंटरैक्ट करने की अनुमति देता है 30।

**English Description (अंग्रेजी विवरण):**
Postiz is an open-source social media scheduler and a powerful self-hosted alternative to Hootsuite. It supports X (Twitter), LinkedIn, Facebook, etc. Integration: An agent creates a video, writes a caption using an LLM, and schedules it across all platforms simultaneously using the Postiz API 29. Instagrapi is an unofficial API wrapper for Instagram that allows agents to upload photos/videos and interact without needing a phone 30.

**4.2. एसईओ और वेब विश्लेषण (SEO & Web Analysis)**

**Hindi Description (हिंदी विवरण):**
Python SEO Analyzer साइट की संरचना का विश्लेषण करता है, पृष्ठों को क्रॉल करता है, और एसईओ मुद्दों (मिसिंग मेटा टैग, टूटे हुए लिंक) की पहचान करता है। एजेंट का कार्य: समय-समय पर आपकी प्रोजेक्ट वेबसाइट का ऑडिट करें और सुधारों की रिपोर्ट तैयार करें 31। Google Search Console API खोज प्रदर्शन पर डेटा प्रदान करता है। एक "विश्लेषक एज��ंट" कम प्रदर्शन वाले कीवर्ड खोजने के लिए इस एपीआईआई का उपयोग कर सकता है और एक "लेखक एजेंट" को उन शब्दों को लक्षित करने हुए नए ब्लॉग पोस्ट बनाने का निर्देश दे सकता है 33। Matomo और Plausible जैसे ओपन-सोर्स एनालिटिक्स टूल Google Analytics के गोपनीय-अनुकूल विकल्प प्रदान करते हैं। इनका डेटा एजेंटों को यह समझने में मदद करता है कि कौन सी ऐतिहासिक फ़िल्में या ब्लॉग पोस्ट सबसे अच्छा प्रदर्शन कर रहे हैं, जिससे "स्व-सुधार लूप" (Self-Correction Loop) संभव होता है।

**English Description (अंग्रेजी विवरण):**
Python SEO Analyzer analyzes site structure, crawls pages, and identifies SEO issues (missing meta tags, broken links). Agent's task: periodically audit your project website and prepare reports on improvements 31. Google Search Console API provides data on search performance. An "analyst agent" can use this API to find underperforming keywords and instruct a "writer agent" to create new blog posts targeting those words 33. Open-source analytics tools like Matomo and Plausible offer privacy-friendly alternatives to Google Analytics. Their data helps agents understand which historical films or blog posts are performing best, enabling a "Self-Correction Loop."
