# Presentation Builder

Define audience, decision, length, and evidence. Build a story arc before styling; one main point per slide. Use a coherent theme, varied layouts, legible typography, cited claims, and direct chart labels. Avoid dense paragraphs/fake data. Render every slide and inspect text fit/cropping/contrast before delivery.
