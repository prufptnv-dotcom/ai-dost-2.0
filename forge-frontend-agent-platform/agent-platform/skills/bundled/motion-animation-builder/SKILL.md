# Motion Animation Builder

Use motion to communicate state or continuity, not decoration. Prefer CSS/Web Animations for UI and the existing media toolchain for long sequences. Avoid layout thrash, honor reduced motion, provide pause/skip when needed, and inspect frame rate/mobile/reduced-motion states. Confirm animation never blocks core tasks.
