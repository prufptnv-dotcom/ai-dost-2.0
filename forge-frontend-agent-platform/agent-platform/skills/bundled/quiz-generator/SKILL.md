# Quiz Generator

Identify objective, audience, level, question count/type, and source. Build a coverage blueprint. Write unambiguous stems, plausible distractors, one defensible key, and concise explanations. Verify every answer against the source, remove duplicates/bias/clues, and validate exported answer-key alignment/accessibility.
