# Game Prototype Builder

Infer genre/device/input/success condition; state defaults. Build a vertical slice: start, core mechanic, feedback, win/fail, restart. Reuse the project engine; separate state/input/rendering; add pause, touch/keyboard controls, responsive canvas, and performance limits. Test the full loop and note asset provenance. Do not build an elaborate engine before one loop works.
