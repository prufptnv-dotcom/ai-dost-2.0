# Three D Scene Builder

Inspect renderer/assets/target devices. Plan scene graph, camera, materials, lighting, loading/error/fallback states. Reuse/compress assets; lazy-load noncritical scenes. Support resize, touch/keyboard, reduced motion, and accessible non-WebGL fallback. Validate frame rate, memory, context loss, and screenshots. Keep the scene purposeful and performant.
