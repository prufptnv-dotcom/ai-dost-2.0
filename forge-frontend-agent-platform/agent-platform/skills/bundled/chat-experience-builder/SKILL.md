# Chat Experience Builder

Map user message → durable job/session → streamed events → result. Distinguish planning, real tool execution, approval, retry, cancellation, and completion; never fabricate status. Preserve drafts, support keyboard send/stop/retry, link generated artifacts, and expose data-sharing approvals. Test slow, failed, interrupted, mobile, and multi-turn cases.
