# Image Art Director

Define purpose/audience/placement/aspect/palette/subject/crop. Write art direction that avoids fake text/logos, clutter, and clichés. Generate only when imagery improves the result. Inspect artifacts, crop, contrast, provenance, and brand fit. Save suitable format/size plus alt text and usage notes.
