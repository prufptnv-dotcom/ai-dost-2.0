# Pdf Document Builder

Confirm audience, size, brand, sections, citations, and format. Outline before writing; preserve sources. Use consistent type/contrast and deliberate page breaks. Generate, extract text, render every page, and inspect clipping, blank pages, broken glyphs, and overflow. Deliver editable source when requested; never claim validity without rendering.
