Rules

05

✓ Do

  • Ek hi accent (indigo) — buttons, links, focus; baaki sirf semantic status colors
  • Users ko hamesha human naam dikhao — "Todo Pro", kabhi raw slug nahi
  • Errors ek baar, politely — ek inline notice + retry, repeat red messages nahi
  • 8px grid, 1px hairline borders (rgba white .06–.08), soft single shadow per layer
  • Mono font sirf code/IDs/timestamps me — body text me kabhi nahi

✕ Don't

  • Rainbow badge soup — GOAL/ARCH/CODE/RESEARCH har rang alag nahi
  • Internal dev language UI me — "P7 Milestone", "DELEGATING", "copilot-mutm69we"
  • Database triples user ko dikhana — node_x > [defines] > node_y
  • Ek hi screen par 30+ controls — grouped icon buttons banao
  • White-on-white preview, overlapping panels, broken mobile layout
