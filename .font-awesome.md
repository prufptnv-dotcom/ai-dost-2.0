## Integration

- **Method:** React components via @fortawesome/react-fontawesome (individual imports, no Kit)
- **Version:** 7.3.1 (free-solid, free-regular, free-brands, fontawesome-svg-core 7.3.1, react-fontawesome 3.5.0)
- **License:** Free
- **Families:** classic

## Defaults

- **Style:** solid
- **Family:** classic

## Import Pattern

- Individual imports: `import { faCartShopping } from '@fortawesome/free-solid-svg-icons'`
- Component: `<FontAwesomeIcon icon={faCartShopping} />`
- Brand logos: `import { faGithub } from '@fortawesome/free-brands-svg-icons'`
- Next.js: `@fortawesome/fontawesome-svg-core/styles.css` imported in `frontend/pages/_app.js` with `config.autoAddCss = false` (official Next.js pattern — warna icons HUGE render hote hain)

## Conventions

- Site chrome uses the shared wrapper `frontend/components/ui/AppIcon.jsx`:
  `<AppIcon name="search" size={15} className="..." />` (name = APP_ICONS key, unknown → `circle` fallback; `loader` auto-spins)
- Naya code me `lucide-react` import NA karein — baaki ~90 files me abhi bhi lucide hai (incremental migration, same AppIcon pattern se)
- Copilot-generated projects: `@fortawesome/*` deps + `FontAwesomeIcon` + individual `fa*` imports; `lucide-react`, emoji-as-icons aur hand-written `<svg>` icons FORBIDDEN (scaffold system prompt + golden templates + preview renderer enforce karte hain)
