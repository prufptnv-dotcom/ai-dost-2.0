# Frontend Ui Designer

1. Identify the primary task and focus the first viewport.
2. Define reusable color, typography, spacing, and component states.
3. Include loading/empty/error/focus/disabled/success states; do not rely on color alone.
4. Keep layouts responsive, keyboard-accessible, touch-friendly, and compatible with reduced motion.
5. Render and inspect desktop/mobile screenshots; fix overflow, clipping, and hierarchy issues.

Use intentional imagery when useful; avoid fake logos, pseudo-text, and weak placeholders.
