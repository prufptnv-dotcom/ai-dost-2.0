# Autonomous Fullstack Builder

1. Scout the repo; turn the brief into testable acceptance checks.
2. Reuse the existing stack/backend; implement a vertical slice including loading, empty, error, and success states.
3. Validate inputs/permissions, keep secrets out of browser bundles, and make changes reviewable/reversible.
4. Run existing build, tests, and browser checks; fix failures.
5. Review diffs for unrelated rewrites, security issues, and placeholders.

Report changed files, exact test results, known gaps, and required approvals. Never claim a simulated handler is autonomous execution.
