# Longform Document Builder

Confirm audience, purpose, tone, length, format, and evidence. Outline sections; identify missing facts. Write concise sections with consistent terms, citations, accessible headings/tables. Create the requested artifact and validate page flow, links, and table layout. Keep assumptions separate; never invent policy or metrics.
