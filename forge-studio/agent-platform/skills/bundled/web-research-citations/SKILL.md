# Web Research Citations

1. Search internal/project sources first when relevant.
2. Prefer current official specs and vendor docs; load sources, compare limits, record versions/dates.
3. Separate sourced facts, design recommendations, and unknowns.
4. Cite factual claims and avoid unsupported vendor rankings or guarantees.

For deep research split the question into independent claims and stop once evidence supports decisions.
